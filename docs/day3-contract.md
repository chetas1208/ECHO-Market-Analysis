Rules that apply to everything
- Scores (severity/novelty/corroboration/confidence) are HEURISTIC in [0,1], deterministic, NEVER called probabilities. Channels are directional pressure in [-1,1], NOT expected % moves.
- Unavailable stays unavailable (None / omitted / lower confidence); never invent sources, locations, channels.
- External text is untrusted: no eval, no SQL interpolation (parametrized only), frontend never renders raw HTML (React text only).
- Provider payload objects stop at the adapter; everything downstream uses `RawWorldEvent`/`NormalizedWorldEvent`.
- Deterministic: no wall clock inside pure functions (pass `now`), no random.
- Tests: `backend/tests/world/test_<module>.py`, pure, no network/DB unless your task says so (then unique `TEST_DATABASE_URL=…/echo_<slug>_test`, drop after). Ruff line 100. Report ≤8 lines.

## Modules and signatures (backend/app/world/)

`taxonomy.py`
- `classify(raw: RawWorldEvent) -> tuple[EventClass, float, list[str]]` → (class, classification_certainty 0..1, matched_evidence terms). Order: provider categories/tags (explicit mapping table) → headline/body keyword rules (word-boundary, case-insens., multi-word phrases) → `OTHER` with certainty 0.2. Deterministic tie-break by fixed class priority. `CLASS_LABELS: dict[EventClass,str]`, `CATEGORY_GROUP: dict[EventClass,str]` → UI filter group in {"geopolitics","energy","supply_chain","technology","macro","other"}.

`entities.py`
- `normalize_entity(name: str) -> NormalizedEntity | None` (alias table: US/U.S./USA/United States→"United States"; NVIDIA/Nvidia Corp./NVIDIA Corporation→"NVIDIA" (kind company; include tickers map `COMPANY_TICKERS`); countries; commodities (crude oil/Brent/WTI→"crude oil"); infrastructure (Strait of Hormuz, Suez Canal, Taiwan Strait, Panama Canal, Port of Shanghai, TSMC fabs…); organizations (OPEC, NATO)).
- `extract_entities(raw: RawWorldEvent) -> list[NormalizedEntity]`: provider-supplied entities/country/region first, then dictionary scan of headline/body (deterministic, longest-match), de-duplicated, stable order. No ML.

`geo.py`
- `normalize_geo(raw: RawWorldEvent, entities: list[NormalizedEntity]) -> GeoInfo`: ISO2 from country name/alias table; preserve upstream lat/lon; chokepoint gazetteer (name→(lat,lon,region)) fills only when the chokepoint is named; unresolved → `resolved=False`, fields None. `location_key(geo) -> str` stable key (chokepoint > city > country > region > "unknown").

`channels.py`
- `CHANNELS: tuple[str,...]` vocabulary exactly: oil_supply, natural_gas_supply, energy_prices, shipping_capacity, shipping_costs, port_capacity, semiconductor_supply, compute_supply, commodity_supply, commodity_prices, consumer_demand, industrial_demand, interest_rates, credit_conditions, regulatory_risk, geopolitical_risk, cybersecurity_risk, infrastructure_availability, global_trade.
- `extract_channels(event_class, entities, geo, raw, severity_hint: float) -> tuple[dict[str,float], dict[str,list[str]]]` → (channels, evidence). Layer 1 class→channel base priors (e.g. SHIPPING_DISRUPTION: shipping_capacity −, shipping_costs +, global_trade −); Layer 2 evidence modifiers from entities/geo (Strait of Hormuz/oil → oil_supply −, energy_prices +; Taiwan+semiconductor terms → semiconductor_supply −, compute_supply −); scale by `severity_hint` (0..1); clamp every value to [-1,1]; drop |v|<0.05; evidence strings name the rule (e.g. "class:shipping_disruption", "entity:Strait of Hormuz"). Deterministic, no text model required.

`fingerprint.py`
- `event_fingerprint(event_class, entities, geo, occurred_at, dedup: DedupConfig) -> str` = sha1 hex of `class|sorted canonical entity keys (countries/regions/infrastructure/companies)|location_key|time_bucket`. Time bucket = floor(occurred_at / time_bucket_hours).
- `text_tokens(headline: str) -> frozenset[str]` (lowercase, stopword removal, light stemming); `text_similarity(a: frozenset, b: frozenset) -> float` (max of Jaccard and containment).
- `is_same_event(a: EventKey, b: EventKey, dedup: DedupConfig) -> tuple[bool, float, str]` where `EventKey` (dataclass in fingerprint.py: event_class, entity_keys: frozenset[str], location_key: str, occurred_at, tokens: frozenset[str]) → (same, score, reason). Same requires: same event_class family AND (entity/location overlap) AND within `max_merge_window_hours` AND text_similarity ≥ threshold OR identical fingerprint. Earthquake vs aftershock 6 h apart w/ different magnitude wording must NOT merge (distinct: different time bucket + "aftershock" token treated as distinguishing).

`sources.py`
- `source_group(source_name: str, source_url: str | None) -> str` (publisher family via domain/name table: reuters, ap, bloomberg, afp, …; unknown → normalized domain or name).
- `classify_independence(refs: Sequence[SourceRef]) -> list[SourceIndependence]` (`SourceIndependence(ref_index, group, independent: bool, syndicated_of: str|None)`): first source per group independent; same group again = duplicate copy; text/attribution markers ("(Reuters)", "via Reuters", `syndicated_from`) mark syndication of that group; aggregator/WM re-exports of a wire count as syndicated. Document limitations in module docstring.

`scoring/severity.py`: `score_severity(event_class, entities, geo, raw, cfg: SeverityConfig) -> tuple[float, dict]` — class base table (documented), bonuses per SeverityConfig (scope, critical infrastructure/chokepoint, source magnitude e.g. richter ≥7, provider importance blend); clamp [0,1]; returns component breakdown. Severity is NOT sentiment.
`scoring/corroboration.py`: `score_corroboration(refs, independence: list[SourceIndependence], cfg: CorroborationConfig) -> tuple[float, dict]` — effective_sources = independent + syndicated_weight·syndicated; base = 1 − exp(−k·effective); blend with diversity (distinct groups/ total); provider reliability nudges; zero sources → 0.0. Monotone non-decreasing when an independent source is added; syndicated copy adds strictly less than an independent one.
`scoring/novelty.py`: `score_novelty(candidate: EventKey, recent: Sequence[EventKey], cfg: NoveltyConfig, now: datetime) -> tuple[float, dict]` — 1 − max over recent within lookback of weighted similarity (entity Jaccard, location match, class match, text similarity) × time decay; empty history → 1.0 (first report).
`scoring/confidence.py`: `score_confidence(*, classification_certainty, geo_resolved, entity_count, corroboration, source_reliability_mean: float|None, has_text: bool) -> tuple[float, dict]` — weighted deterministic blend documented in docstring; incomplete data lowers it; never > 0.95.
`scoring/__init__.py`: `score_event(...)` is written LATER by the pipeline agent; do not add it.

`normalizer.py` (wave 2): `normalize(raw: RawWorldEvent, *, now: datetime, settings: WorldSettings, text_analyzer=None) -> NormalizedWorldEvent` composes taxonomy→entities→geo→severity→channels→fingerprint (scores with novelty/corroboration/confidence filled by the pipeline where history is needed). Malformed input raises `NormalizationError` (defined there).

`providers/replay.py`: `ReplayWorldEventProvider(events: Sequence[RawWorldEvent], speed=0.0, sleep=asyncio.sleep, fail_after: int|None=None)`; deterministic order (occurred_at, provider_event_id, headline); `health()` state REPLAY / mode REPLAY; all emitted events `is_replay=True` and every `SourceRef.provider == "replay"`; `fetch_recent(since)` returns events with occurred_at > since; stream ends on exhaustion; `fail_after` raises ConnectionError once then resumes (failure simulation).
`fixtures.py`: `WORLD_FIXTURES: dict[str, WorldFixture]` (`WorldFixture(raw: RawWorldEvent, expected_class: EventClass, expected_channels: dict[str, int] (channel → expected sign −1/+1), expected_country: str|None)`) for: `hormuz` (SHIPPING_DISRUPTION/ or GEOPOLITICAL, occurred 2026-09-16 09:00Z), `taiwan_quake` (NATURAL_DISASTER, semiconductor risk), `cloud_outage` (INFRASTRUCTURE_OUTAGE), `oil_infra` (ENERGY_SUPPLY_DISRUPTION), `cyber_incident` (CYBER_INCIDENT), `sanction` (SANCTION). Each ≥1 SourceRef (replay provider, plausible fictional/clearly-mock publisher names ok; headline clearly synthetic-realistic, `is_replay=True`). `build_dedup_scenarios() -> dict[str, list[RawWorldEvent]]`: `exact_duplicate` (same event twice), `independent_sources` (hormuz reported by 4 distinct publishers), `syndicated` (Reuters original + 3 republications crediting Reuters), `aftershock` (quake at 10:00 and aftershock 16:00 — must stay distinct), `update` (later report adds magnitude/severity info to the same event). All deterministic.

`text/analyzer.py`: `class TextAnalysis(BaseModel): label: Literal["positive","negative","neutral"]; scores: dict[str,float]; model: str; latency_ms: float|None`; `class AnalyzerStatus(StrEnum): AVAILABLE, LOADING, UNAVAILABLE, DISABLED`; `class FinancialTextAnalyzer(Protocol): status: AnalyzerStatus; def analyze(self, text: str) -> TextAnalysis | None` (None when unavailable — never raises); `NullAnalyzer` (DISABLED); `CachingAnalyzer(inner, max_items)` keyed by sha256(text) (LRU, bounded); `ModernFinBERTAnalyzer` (text/modernfinbert.py): lazy import/load on first analyze (thread-safe), no import of torch/transformers at module import, status UNAVAILABLE on any failure (no crash, no network at startup), pinned model id+revision constant, batch `analyze_many`. Optional deps go in a uv group `text` (NOT default deps). ModernFinBERT is used ONLY for financial/market-relevant text (company/earnings/market headlines), never as a geopolitical reasoner.

`world/pipeline.py` (wave 2): `WorldIngestPipeline(session_factory, settings, analyzer)` with `async ingest(raw: RawWorldEvent) -> IngestResult(action: "created"|"merged"|"duplicate"|"rejected", event_id, source_added: bool, corroboration_before/after, reason)`: normalize → load recent candidates (same time window, DB) → `is_same_event` → merge (append `event_sources`, recompute corroboration/confidence/severity, write `event_revisions` snapshot of prior state, update `canonical_events` score columns + `revision`/`updated_at`) or create (canonical_events row `source_type=world`, `event_type=<class>`, fingerprint row, sources rows). Exact duplicate = same (provider, provider_event_id) OR same raw content hash → `duplicate`, no new source row. Malformed → `world_ingest_errors` row (dead-letter) + `rejected`; never raises. Each stage logs structured events (world_event_received, world_event_normalized, duplicate_event_detected, source_added, economic_channels_extracted, event_persisted; never full article text at INFO).
`world/runtime.py` (wave 2): `WorldRuntime(settings, session_factory)`: start()/stop(); provider selection (off→OFFLINE; replay→ReplayWorldEventProvider(WORLD_FIXTURES + dedup scenarios? no: fixtures only); world_monitor→WorldMonitorProvider supervised; unconfigured→UNCONFIGURED); consumer task calling pipeline.ingest; facade: `mode -> WorldMode`, `health() -> WorldProviderHealth`, `counters() -> dict` (received, created, merged, duplicates, rejected, last_event_at), `analyzer_status -> str`. Wired into main.py lifespan; failure never blocks startup.
